# Análise de Desempenho Acadêmico

## Sobre o projeto

Este projeto foi desenvolvido para praticar conceitos de **Python, Pandas, visualização de dados e análise estatística**.

O objetivo é analisar uma base de dados acadêmicos e observar a relação entre **frequência, notas e situação final dos alunos**.

> **Observação:** os dados utilizados neste projeto são fictícios e foram criados exclusivamente para fins de estudo e demonstração.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Análises realizadas

Neste projeto foram realizadas as seguintes análises:

- Cálculo da média das notas dos alunos;
- Classificação dos alunos como aprovados ou reprovados;
- Cálculo da taxa de aprovação da turma;
- Identificação da maior e da menor média;
- Visualização do desempenho individual dos alunos;
- Comparação entre alunos aprovados e reprovados;
- Análise da relação entre frequência e média;
- Cálculo da correlação entre frequência e desempenho;
- Análise dos alunos reprovados.

## Critério de aprovação

Para fins deste projeto, foi considerada aprovação a **média igual ou superior a 6,0**.

Esse critério é fictício e foi definido exclusivamente para fins de estudo.

## Principais resultados

A análise da base fictícia mostrou:

- **10 alunos** analisados;
- **60% de aprovação**;
- **Média geral de 6,88**;
- **Maior média de 9,25**;
- **Menor média de 4,00**;
- Correlação de aproximadamente **0,97** entre frequência e média.

Nesta base fictícia, foi observada uma forte relação positiva entre frequência e desempenho. Isso significa que alunos com maior frequência tendem a apresentar médias maiores. Porém, **correlação não significa causalidade**.
